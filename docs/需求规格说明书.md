## 1. 目的与范围

本文把已经确认的决定写成可验收的需求，供后续的设计、实现和测试使用。第一版是一个面向更多人使用的 Windows 桌面工具：用户选择本机视频，完成查看信息、提取、裁剪、合并、转码和音轨处理。处理由随包的 FFmpeg 在本机完成。

最初采纳的八个功能点，在本文中的位置如下。

| 功能点 | 本文位置 |
| --- | --- |
| 媒体信息 | 4.2 |
| 提取音频 | 4.3 |
| 提取字幕 | 4.4 |
| 字幕封装 | 4.5 |
| 裁剪与合并 | 4.6、4.7 |
| 换容器或压缩 | 4.8 |
| 替换或去掉音轨，以及音量 | 4.9 |
| 批量 | 4.1。每个功能都能处理整个文件夹，批量不单独做成另一种算法 |

第一版同时提供安装包和绿色压缩包。界面、报错和本文使用简体中文。源代码里的名字、注释，以及调用 FFmpeg 的参数使用英文。

### 1.1 编写时补上的默认条款

下面这些条款在提问里没有单独立项。为实现和验收不被卡住，本文把它们写成必须遵守的规则。评审时如果要改，直接改对应编号。

| 编号 | 默认规则 |
| --- | --- |
| NFR-01 | 仅支持 64 位 Windows 10 及更高版本 |
| NFR-03 | 文件只在本机处理，不上传，不需要账号 |
| NFR-04 | 只调用随包的 FFmpeg，不使用系统里另装的那一份 |
| FR-C-07 | 只处理一个文件时，取消直接生效，不再询问 |
| FR-C-12 | 第一版不记住上次填写的参数 |
| FR-C-13 | 配套文件有多个时，按本文规定的顺序取第一个，并在结果说明里写明用了哪一个 |
| FR-A-04 | 提取音频使用固定质量，界面不提供音频码率输入 |
| FR-A-05 | 音量范围是 0 到 200 的整数，100 为原音量，默认 100 |
| FR-T-04 | 裁剪按指定时间重新编码，成片时长与设定相差不超过 1 秒 |
| FR-V-04 | 只换容器时，目标容器放不下现有编码，就判定失败，不自动改成压缩 |
| FR-V-06 | 压缩的视频码率留空表示默认质量；填写则使用 1 到 200000 的整数，单位 kbps |

| FR-G-03 | 合并以第一段的分辨率和帧率为准，其他片段缩放到相同尺寸，此时允许放大 |
| FR-G-05 | 合并是一次整体任务：任一输入读不出，整次合并失败 |

## 2. 用户与运行环境

使用者不要求会使用命令行。使用者能够把工具安装或解压到 Windows 电脑，能选择自己的视频文件，并看懂中文结果。

工具必须在 64 位 Windows 10 及更高版本上运行（NFR-01）。界面在处理过程中保持可点击，取消按钮始终可用（NFR-02）。所有处理都在本机完成，工具不上传文件，也不要求注册或登录（NFR-03）。

工具只调用随包的 FFmpeg 可执行文件（NFR-04）。随包文件缺失或无法启动时，用中文说明「找不到随包的 FFmpeg」，不继续处理。

## 3. 安装、关于页与许可证

FR-P-01 第一版提供两种发布物，功能相同，都自带 Windows 64 位 FFmpeg：

- 安装包：用户可选择安装目录，开始菜单中有快捷方式，并提供卸载。卸载只删除本工具安装的程序文件，不删除用户的视频和已经生成的输出。
- 绿色压缩包：解压后直接运行，不写入开始菜单。

FR-P-02 两种发布物的软件版本号必须一致。关于页展示本工具版本号和随包 FFmpeg 的版本号。

FR-P-03 随包 FFmpeg 使用包含 GPL 组件的构建。发布物中必须带有本工具的 GPL 许可证文本、FFmpeg 对应的许可证文本，以及 `SOURCE.txt`。关于页提供入口打开这三份文本。`SOURCE.txt` 写明源代码与本工具使用同一版本号，并说明获取方式是与发布物放在一起的源码目录，或关于页所写地址。关于页本身不另外书写网址。

FR-P-04 安装包的安装向导只要求用户选择安装路径。用户在安装路径页确认后，复制文件、写入开始菜单快捷方式和收尾步骤自动完成，不再出现需要用户点选或确认的页面。不提供开始菜单文件夹、附加组件、是否创建桌面快捷方式、是否立即启动等可选步骤。许可证文本按 FR-P-03 随包提供，并在关于页打开，不在安装向导中单独展示许可证页。

## 4. 功能需求

### 4.1 公共规则

FR-C-01 除「合并」外，每个功能都有两种入口：处理当前选中的一个视频，或处理一个文件夹里的视频。合并的入口见 4.7。

FR-C-02 可处理的视频扩展名只有 `.mp4`、`.mkv`、`.avi`、`.mov`、`.webm`，不区分大小写。其他文件忽略。文件夹里一个符合扩展名的文件都读不出时，该项失败并进入清单。

FR-C-03 选择文件夹时，只处理该文件夹直接包含的视频，不进入子文件夹。

FR-C-04 输出写在源文件所在文件夹。工具不修改源文件。输出文件名使用「原名_功能后缀.扩展名」。各功能后缀规定如下。

| 功能 | 后缀 | 扩展示例 |
| --- | --- | --- |
| 媒体信息 | `_info` | `.txt` |
| 提取音频 | `_audio` | `.mp3`、`.m4a`、`.wav`、`.flac` |
| 提取字幕 | `_subtitle` | `.srt`、`.ass`、`.vtt`、`.mkv` |
| 封装字幕 | `_muxed` | `.mkv` |
| 裁剪 | `_trim` | 与规则允许的视频容器一致 |
| 合并 | `_merge` | 用户选择的容器 |
| 只换容器 | `_remux` | 用户选择的容器 |
| 压缩 | `_compress` | 用户选择的容器 |
| 去掉音轨 | `_silent` | 与源容器一致，或按 4.9 改写后的容器 |
| 保留音轨 | `_audiotrack` | 同上 |
| 替换音轨 | `_replaced` | 同上 |

FR-C-05 目标文件名已存在时，不覆盖。在扩展名前依次插入 ` (2)`、` (3)`，直到得到一个不存在的文件名。

FR-C-06 同一时间只运行一个任务。已有任务在进行时，不能开始第二个任务。

FR-C-07 任务进行时，界面显示当前文件名、文件夹任务中的「第几个 / 共几个」，以及取消按钮。能计算出单个文件的完成比例时，显示百分比；计算不出时，显示进行中。合并的进度显示见 FR-G-04。只处理一个文件时，点取消就停止该任务。处理文件夹时，点取消后必须询问：「停掉整个任务」或「只跳过当前文件」。关闭这个询问等于继续处理。

FR-C-08 文件夹任务中，单个文件失败时，跳过该文件并继续后面的文件。任务结束后面展示清单，每一行包含：输入文件名、结果、中文说明。结果只使用这四种：成功、失败、已取消、未处理。成功行还要包含输出文件路径。清单全文可以一键复制。

取消的后果：

- 停掉整个任务：正在写的输出删除；已成功的输出保留；还没开始的文件在清单中记为未处理。
- 只跳过当前文件：正在写的输出删除，该文件记为已取消，然后继续下一个。
- 合并不适用「只跳过当前文件」，见 FR-G-05。

FR-C-09 失败或取消时，必须删除该次未完成的输出。删除不掉时，清单说明中写出这个残留文件的路径。

FR-C-10 用户可见的结论和错误只用简体中文，不展示 FFmpeg 的原始输出。至少要能区分这些情况：找不到随包 FFmpeg、没有可处理的视频、没有音轨、没有字幕、找不到配套文件、时间无效、结束时间超过视频时长、目标容器无法直接容纳现有编码、无法写入、文件无法读取、已取消。无法归类时，说明使用「处理失败，请检查文件是否损坏」。

FR-C-11 选择的文件夹里没有符合 FR-C-02 的视频时，不调用 FFmpeg。结果清单增加一行失败，输入文件名为空，说明为「这个文件夹里没有可处理的视频」。

FR-C-12 通过托盘「退出」结束进程后再打开，各功能回到本文规定的默认值，不恢复上次填写的内容。仅关闭主界面（程序仍在托盘运行）后再显示主界面时，界面状态保持不变。

FR-C-13 文件夹模式下，封装字幕和替换音轨使用与视频同名的配套文件。存在多个配套文件时，只使用优先级最高的一个，并在成功说明中写明实际使用的文件名。

### 4.2 媒体信息

FR-I-01 选中单个视频后，自动显示媒体信息，不必先点开始。字段包括：时长、分辨率、帧率、视频编码、视频码率、每一路音轨、每一路字幕、章节。

每一路音轨显示：序号（从 1 开始）、编码、声道数、语言。没有语言标记时显示「未标记」。读不到码率时显示「未知」。

每一路字幕显示：序号（从 1 开始）、编码、语言、种类。种类只有「文本」或「图像」。

章节显示起始时间和标题。没有标题时只显示起始时间。没有章节时显示「无章节」。

FR-I-02 单个视频的信息可以一键复制。复制的文字与界面上的信息一致，使用 UTF-8。

FR-I-03 用户确认导出后，写成 `原名_info.txt`，编码 UTF-8，内容与界面信息一致。文件夹入口下，每个成功读取的视频各导出一份 txt，界面展示 FR-C-08 规定的清单，不把每个文件的全文都铺在界面上。

### 4.3 提取音频

FR-A-01 用户选择要提取的音轨序号，以及输出格式。格式只有 MP3、M4A（AAC）、WAV、FLAC 四种，默认 MP3。默认音轨是第 1 路。选中单个视频时，序号来自该文件实际探测到的音轨。文件夹模式下，序号固定为第 1 路到第 8 路。

FR-A-02 所选序号在该文件中不存在，或该文件没有音轨时，该项失败，说明「没有音轨」。

FR-A-03 音量按 FR-A-05 应用。音量为 100 时保持原音量；其他值按百分比缩放。

FR-A-04 输出按所选格式重新编码，采样率和声道数与所选音轨一致。界面不提供音频码率。固定参数为：MP3 192 kbps，AAC 192 kbps，WAV 为 16 位 PCM，FLAC 为无损。

FR-A-05 音量输入是 0 到 200 的整数，默认 100。0 表示保留一条静音音轨，与「去掉音轨」不同。提取音频、保留音轨、替换音轨都使用这个音量规则。

### 4.4 提取字幕

FR-S-01 用户选择字幕序号，以及提取格式。格式为 SRT、ASS、VTT、原样，默认 SRT。默认序号是第 1 路。选中单个视频时，序号来自该文件实际探测到的字幕。文件夹模式下，序号固定为第 1 路到第 8 路。

FR-S-02 没有字幕，或序号不存在时，该项失败，说明「没有字幕」。

FR-S-03 文本字幕按所选的 SRT、ASS 或 VTT 导出，编码 UTF-8。用户选择原样时，把该字幕流放进一个只含这路字幕的 MKV，文件名为 `原名_subtitle.mkv`。

FR-S-04 图像字幕在用户选择 SRT、ASS 或 VTT 时失败，说明「这一轨是图像字幕，请选原样」。用户选择原样时，按 FR-S-03 抽出。

### 4.5 封装字幕

FR-M-01 只把外挂的文本字幕封装进 MKV，成为可开关的软字幕。第一版不烧录进画面，也不整体移动字幕时间。

FR-M-02 单个视频时，用户选择一个 `.srt`、`.ass` 或 `.vtt` 文件。输出为 `原名_muxed.mkv`。视频流和音轨复制到新文件中，不重新编码。

FR-M-03 文件夹模式下，为每个视频查找同名配套字幕，优先级为 `.srt`、`.ass`、`.vtt`。一个都没有时，该项失败，说明「找不到同名字幕」。

FR-M-04 字幕文件读不出来时，该项失败，说明「字幕文件无法读取」。

### 4.6 裁剪

FR-T-01 用户用两种方式之一指定时间范围，默认是「开始和结束」：

- 开始时间和结束时间
- 开始时间和时长

时间写法支持 `时:分:秒`、`分:秒` 和秒数。分和秒必须在 0 到 59。例如 `90` 表示 90 秒，`1:30` 表示 1 分 30 秒，`1:02:03` 表示 1 小时 2 分 3 秒。

FR-T-02 开始时间必须大于或等于 0。结束时间必须大于开始时间。时长必须大于 0。「开始加时长」换算成结束时间后再做同样检查。结束时间超过该视频时长时，该项失败，说明「结束时间超过视频时长」。文件夹里的每个视频使用同一组时间；某个视频太短时，只让该视频失败。

FR-T-03 输出容器与源文件相同。源文件是 WebM 时，视频编为 VP9、音频编为 Opus。其他源文件视频编为 H.264、音频编为 AAC。质量使用 4.8 的默认质量。

FR-T-04 裁剪必须对准用户填写的时间。成片时长与设定时长相差不超过 1 秒。

### 4.7 合并

FR-G-01 合并有两种入口：

- 多选至少两个视频，并按用户排好的顺序拼接。输出放在第一个视频所在文件夹，文件名为 `第一个视频原名_merge.容器`。
- 选择一个文件夹。符合 FR-C-02 的视频按文件名自然顺序拼接：数字按数值比较，字母不区分大小写。输出放在该文件夹，文件名为 `文件夹名_merge.容器`。

少于两个视频时不开始，并说明「至少需要两个视频」。

FR-G-02 用户选择输出容器：MP4、MKV 或 WebM，默认 MP4。

FR-G-03 所有片段的视频编码、分辨率、帧率和音频参数一致，并且目标容器能够容纳这些编码时，直接拼接，不重新编码。否则先重新编码再拼接：

- MP4 或 MKV：H.264 + AAC
- WebM：VP9 + Opus
- 分辨率和帧率以第一段为准，其他片段缩放到相同宽高，宽和高取偶数。此缩放允许把较小的画面放大。任一段没有可用的帧率分数时，整次合并失败，说明为「无法读取这个文件：{文件名}」。
- 重编码始终使用默认质量，界面不提供码率。H.264 的质量目标相当于 CRF 23，VP9 相当于 CRF 32。

FR-G-04 合并成功时只产生这一个输出文件。进行中的进度写成「正在合并 1/总数：第一个文件名」，不随后面的片段更换序号和文件名。

FR-G-05 合并是一次整体任务。任何一个输入无法读取时，整次合并失败，删除未完成输出，说明中包含这个输入的文件名。取消合并时直接停止并删除未完成输出，不再询问「只跳过当前文件」。已失败的合并不保留拼到一半的成片。

### 4.8 换容器或压缩

FR-V-01 这个功能分成两种操作，默认是「只换容器」：

- 只换容器
- 压缩

目标容器为 MP4、MKV、WebM，默认 MP4。

FR-V-02 只换容器时，视频流和音轨能复制就复制，不重新编码。分辨率、码率和编码器在这种操作下不可用。目标容器放不下现有编码时，该项失败，说明「目标容器无法直接容纳现有编码」。失败后不自动改做压缩。典型情况包括：把普通 H.264 的 MP4 直接换进 WebM。

FR-V-03 压缩时，用户选择分辨率和视频编码器，并可以填写视频码率。

- 分辨率：原分辨率、1080p、720p，默认原分辨率。1080p 表示高度 1080，720p 表示高度 720，宽度按比例计算并取偶数。
- 目标容器是 MP4 或 MKV 时，视频编码器有 H.264、H.265 和 VP9，默认 H.264，音频编为 AAC。选择 VP9 时音频仍为 AAC。
- 目标容器是 WebM 时，视频固定为 VP9，音频固定为 Opus。界面不提供改成 H.264 或 H.265。

FR-V-04 见 FR-V-02。只换容器失败时保持失败。

FR-V-05 压缩会按目标参数重新编码视频和音频。字幕按这些规则进入输出：MKV 复制全部字幕流；MP4 把文本字幕转为 `mov_text`；WebM 把文本字幕转为 WebVTT。MP4 和 WebM 不保留图像字幕。裁剪不保留字幕。

FR-V-06 视频码率以 kbps 为单位，只接受 1 到 200000 的整数，也可以留空。留空时使用默认质量：H.264 和 H.265 为 CRF 23，VP9 为 CRF 32。填写码率时按该码率编码。这个输入只出现在压缩操作中。压缩时的音频使用固定码率：AAC 160 kbps，Opus 128 kbps。

FR-V-07 源视频高度已经小于或等于所选的 1080p 或 720p 时，保持源高度，不放大。

### 4.9 音轨

这三项都输出新的视频文件，默认保留源容器。新的音频编码无法放进源容器时，改为 MP4，并在成功说明中写明「已改用 MP4」。WebM 源的新音频使用 Opus，其他容器使用 AAC。视频流复制，不重新编码。音量规则见 FR-A-05。

FR-R-01 去掉音轨：输出不含任何音轨。源文件本来就没有音轨时，该项失败，说明「没有音轨」。

FR-R-02 保留音轨：用户选择保留的音轨序号，默认第 1 路。文件夹模式下可选第 1 路到第 8 路。其他音轨不进入输出。序号不存在时失败，说明「没有音轨」。音量为 100 且该音轨能放进输出容器时，复制这路音轨；否则重新编码后再调节音量。

FR-R-03 替换音轨：用外部音频替换全部原音轨。单个视频时，用户选择一个音频文件，扩展名只接受 `.mp3`、`.m4a`、`.wav`、`.flac`。源视频没有音轨时仍然可以替换。

FR-R-04 替换后的成片时长以视频为准。外部音频较短时，视频剩余部分为静音；外部音频较长时，截断到视频结束。

FR-R-05 文件夹模式下，为每个视频查找同名外部音频，优先级为 `.m4a`、`.mp3`、`.wav`、`.flac`。一个都没有时，该项失败，说明「找不到同名音频」。

## 5. 界面要求

FR-U-01 主界面能够完成这些步骤：选择一个视频、多选视频（仅合并）、或选择一个文件夹；选择功能；填写该功能的参数；开始；查看进度并取消；查看结果清单；打开关于页。

FR-U-02 用户可见文字使用简体中文。

FR-U-03 第一版不提供视频或音频播放，也不提供时间轴拖选。

FR-U-04 参数的初始值使用下表。

| 项目 | 默认值 |
| --- | --- |
| 音轨或字幕序号 | 第 1 路 |
| 提取音频格式 | MP3 |
| 提取字幕格式 | SRT |
| 音量 | 100 |
| 裁剪方式 | 开始和结束 |
| 合并或转码容器 | MP4 |
| 转码操作 | 只换容器 |
| 分辨率 | 原分辨率 |
| 视频编码器 | H.264；目标为 WebM 时固定 VP9 |
| 视频码率 | 留空（默认质量） |

FR-U-05 程序运行期间在系统托盘显示图标。托盘图标的右键菜单只有两项：「显示主界面」和「退出」，顺序固定，不提供其他菜单项。

FR-U-06 双击托盘图标，或选择「显示主界面」，都显示并前置主界面。

FR-U-07 点击主界面右上角关闭按钮时，只关闭（隐藏）主界面，不结束进程；托盘图标继续保留。进行中的任务不因关闭主界面而停止。

FR-U-08 只有托盘菜单的「退出」才结束进程。退出时若仍有任务在进行，先按「停掉整个任务」处理（停止进程、删除未完成输出），再退出。

## 6. 不在第一版范围内

下列能力不进入第一版的界面，也不作为验收项：

- 播放预览、时间轴拖选裁剪
- 烧录硬字幕、字幕时间整体偏移
- 处理子文件夹
- 覆盖已有输出
- 记住上次的参数
- 展示或保存 FFmpeg 原始输出
- 手写任意编码器名称
- 调节音频码率
- 使用系统 PATH 中的 FFmpeg
- 账号、网络上传、自动更新

## 7. 验收场景

每条场景都要在安装版和绿色版上各检查一次「能完成」，两套发布物的结果规则相同。

| 编号 | 通过标准 |
| --- | --- |
| AC-01 | 在 64 位 Windows 10 上安装后，能从开始菜单打开；绿色版解压后能直接打开。关于页能看到两个版本号和两份许可证 |
| AC-17 | 安装向导只需在安装路径页确认一次。确认后不再出现需要用户点选或确认的页面，安装自动完成，开始菜单中出现快捷方式 |
| AC-18 | 启动后托盘出现图标；右键只有「显示主界面」和「退出」。关闭主界面后进程仍在，托盘仍在；双击托盘或选「显示主界面」可再次打开主界面。选「退出」后托盘消失、进程结束 |
| AC-02 | 选中一个含多路音轨、多路字幕和章节的 MKV，界面出现 4.2 的全部字段；复制内容和导出的 txt 与界面一致 |
| AC-03 | 从一个多音轨视频抽出第 2 路为 MP3、WAV、FLAC 和 M4A。音量设为 50 时，听感明显低于音量 100 的成片 |
| AC-04 | 文本字幕能导出 SRT、ASS、VTT。图像字幕选择 SRT 时失败并给出规定中文；选择原样时得到 MKV |
| AC-05 | 单个视频选择外挂 SRT 后得到可开关字幕的 MKV。文件夹中只有同名 ASS 的视频成功，没有配套字幕的视频出现在失败清单，其他视频继续完成 |
| AC-06 | 对一个 60 秒视频使用开始 `0:10`、时长 `15`，成片时长在 14 到 16 秒之间。结束时间填得超过时长时，该文件失败且源文件仍在 |
| AC-07 | 三个分辨率不同的 MP4 按指定顺序合并为一个文件，顺序与排列一致，三个画面都能播完。故意加入一个损坏文件时，得不到成片，并有中文说明指出该文件 |
| AC-08 | 文件夹合并的顺序是文件名自然顺序：`clip2` 排在 `clip10` 前面 |
| AC-09 | H.264 的 MP4 只换容器为 MKV 时能够播放，且耗时明显短于同一文件压到 720p。同一文件只换容器为 WebM 时失败，源文件不变，没有新的 WebM |
| AC-10 | 压缩为 720p、H.265、填写码率 1500 kbps 的 MP4 后，高度为 720（源高度大于 720 时），且能播放出声音。源高度为 480 时选择 1080p，输出高度仍为 480 |
| AC-11 | WebM 压缩得到的视频编码是 VP9、音频编码是 Opus |
| AC-12 | 去掉音轨后的文件没有音轨。保留第 1 路后不再包含第 2 路。用一段更短的 WAV 替换后，成片时长仍等于视频时长，后段为静音 |
| AC-13 | 输出写在源文件旁边，名字带功能后缀。重复执行同一次操作会得到 ` (2)`，第一次的输出还在 |
| AC-14 | 文件夹任务中途选择「只跳过当前文件」后，当前半成品消失，后续文件继续。选择「停掉整个任务」后，后续文件记为未处理，已成功文件还在 |
| AC-15 | 处理过程中窗口仍能移动，取消按钮可以点击。结果清单能整份复制，其中的失败原因是中文，界面上看不到 FFmpeg 的原始输出 |
| AC-16 | 卸载安装版之后，程序快捷方式消失；用户原来的视频和输出文件还在 |
